# Connect & Sync Hub

agregale a esta app, que se pueda conectar con aplicaciones de terceros como garmin, strava, etc

Crear la app web RUN importando la base del proyecto con la pantalla de Apps y Dispositivos conectados (Garmin Connect, Strava, Apple Health, Coros), opciones de sincronización automática y manual, estado de vinculación y flujo para importar actividades.
